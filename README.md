# Разработка интернет-приложений 2026

## Расчет количества вещества по продуктам сгорания

Разработанное приложение позволит лаборантам создавать и формировать заявки на расчет количества вещества в образце простого органического соединения, а экспертам завершать или отклонять данные заявки.
